# CLINC150 source and attribution

`clinc_oos_full.json` is the original full dataset file from [clinc/oos-eval](https://github.com/clinc/oos-eval/blob/828f8093932c8fe6ca7936c3d2e52903b1c523de/data/data_full.json), distributed under the [Creative Commons Attribution 3.0 Unported license](https://creativecommons.org/licenses/by/3.0/).

Attribute the dataset to Stefan Larson, Anish Mahendran, Joseph Peper, Christopher Clarke, Andrew Lee, Parker Hill, Jonathan Kummerfeld, Kevin Leach, Mike Laurenzano, Lingjia Tang, and Jason Mars, “An Evaluation Dataset for Intent Classification and Out-of-Scope Prediction,” EMNLP-IJCNLP 2019. [Paper](https://aclanthology.org/D19-1131/).

The dataset is included unchanged. Its source repository, exact commit, and SHA-256 are recorded in `project_config.json` and `DATA_CARD.md`. The software and documentation authored for this portfolio project are separately licensed under MIT. The pretrained Google BERT-Tiny weights are separately licensed under Apache 2.0.
